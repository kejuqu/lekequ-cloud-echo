# 登顶寻囊 · 四季回响

基于 `req.md` 当前 **5 峰详细设定**实现的纯前端 3D 登山解谜动作游戏。React + TypeScript + Three.js + Cannon-es + Web Audio，无账号、无需服务端。文档后段遗留的“18峰”技术示例不作为关卡数量；“可扩展功能”列出的联机、皮肤、DLC 等仍属于后续范围。

## 运行

建议 Node.js 22.18+，使用 npm（`package-lock.json` 为当前依赖锁文件）。

```sh
npm install
npm run dev
npm test
npm run build
```

打开 Vite 输出的 Local 地址；手机连接同一 Wi-Fi 后打开 Network 地址。`dist/` 可部署到静态托管。浏览器需要支持 WebGL。音频需点击开始后启用；手机震动取决于浏览器与硬件支持。

## 操作

- **WASD / 方向键**：沿当前山道前后、横向移动。移动不限制在路内，踩出山体会坠落。
- **空格**：默认向前小跳，无需按住 W；第五关向前跳跃可越过断裂台阶。站进凹坑停下蓄力，金色窗口内**单按空格**即可自动借势落上对应高台。金光判定带短暂输入容错，普通地面静止时不会继续下滑。冬峰窗口更短；蓄力过晚会滑落。
- **左 Shift**：按住冲刺，消耗体力。第 3–5 关的第一段原减速带改为交错升降的大刀，碰到立即死亡，需等刀升起后通过；后续橙黑反向减速带仍会反推并消耗体力。
- **左键**：点击道路显示左右交替的足迹路线与终点箭头，人物自动步行到目标点；点击怪物或按住鼠标射击；拖动旋转视角。WASD / 摇杆输入随时取消点击移动。对准怪物点击或使用中心准星，带小范围辅助瞄准；地形阻挡射线。
- **武器自动拾取**：靠近弓箭、手枪即可获得，无需快捷键；拾取后角色手中显示对应的低多边形弓（弓臂、弓弦、箭）或手枪（枪管、套筒、握把）。弓弦与枪声使用不同的合成音效。手枪与弹药补给分开放置：第 4 关弹药在 64 米附近，第 5 关在 75 米附近，不再紧邻山脚手枪。
- **E**：开启补给、拾取锦囊；引水、攀绳、激活守护石碑。走到山顶红旗附近会自动校验并弹出登顶成功标识。
- **1 / 2**：弓箭 / 手枪。弓箭无限箭矢、伤害低；手枪有限弹药、伤害高，补给箱 15 秒刷新。
- **F**：拾取望远镜后切换远眺。**Q**：满能量释放击退冲击波，25 秒冷却，不直接击杀 BOSS。
- **R**：确认重新开始。**Esc**：暂停。

触屏端使用左摇杆、右侧跳跃/射击/冲刺/交互/大招按钮；右侧空白区域滑动转镜头。上方支持切换武器、望远镜和重置。设置支持摇杆左侧/左下位置、透明度、按钮缩放、冲刺位置交换、镜头灵敏度、固定镜头、声音和震动。

## 新增：绳索陡坡与追兽疾行

秋峰（60–65 米）、冬峰（105–109 米）、终峰（53–58 米）新增必须抓绳才能攀登的陡坡：到绳索底部按 E 抓绳，W / 上推摇杆攀爬，S 下滑，E 松手。角色会沿绳索连续攀爬，而不是瞬间传送。终章原有悬崖取字绳索仍可交互。

第 5 峰在 128 米处设追兽山门，按 E 进入独立的 **30 秒**追逐路线（另有 3 秒准备倒计时）。角色自动前进，沿途需及时快速转弯：A / D、方向键、左右按钮、点击屏幕左右两侧或横向滑动均可；横木临近时按 Space / 跳跃。转错或没及时转会被追兽扑倒，撞横木会缩短安全距离。暂停时追逐计时也暂停；未完成无法开启 134 米山门或最终锦囊，失败重生后需要重新挑战。

## 规则与存档

收集全部字块后锦囊显形，拾取后到红旗按 E；只有锦囊成语与红旗完全相同才通关。缺字、未拾锦囊、终章 BOSS 存活均无法通关。洞口守卫存活时无法拿取秋峰锦囊。

第 3、4、5 峰均有紫色吐弹怪兽，会预热嘴部后朝玩家吐出可见子弹。子弹会被地形阻挡，也可横移、跳跃躲避。

触碰炸弹、被咬、中弹、坠崖都会失败。角色先在道路上倒地停留 **3 秒**，再重生。**已收集字块保留**；锦囊、武器弹药、能量、增益、怪物、炸弹和机关重置。春峰教学失误回教学检查点，其余致命事件回山脚。重开弹窗另提供“连同字块一起重置”。通关标记、字块与设置保存在 `LocalStorage` 的 `mountaineer-v2`；旧版本的 A–Z 通关不会误算为新成语关卡通关。存储不可用时仍可在本次会话游玩。

## 实现结构

- `src/levels.ts`：五峰数据、山体高度、断崖与分支。
- `src/chase.ts`：30 秒追逐、折线道路、急转窗口、障碍与追兽距离。
- `src/rules.ts`：成语校验、存档校验、技能窗口与武器规则。
- `src/simulation.ts`：60 Hz 固定步长 Cannon-es 物理、碰撞、战斗、AI、机关、重置。
- `src/game.ts`：Three.js 场景、角色/怪物分部动画、布旗形变、天气、粒子、射线瞄准、输入及资源释放。
- `src/audio.ts`：本地实时合成配乐、拾取/战斗/爆炸音效，无外部音频采样。
- `src/main.tsx` / `src/style.css`：React 界面、山峰菜单、触屏操作与设置。
- `tests/game.test.mjs` / `tests/new-gameplay.test.mjs`：规则、物理及本轮交互回归测试。

场景与模型为程序生成的低多边形资源，按当前关卡构建并在换关时释放；游戏引擎延迟加载，不需要额外下载 GLB 或外部素材。怪物采用分部关节动画，未引入外部骨骼资产。音景为实时合成循环，随关卡与 BOSS 阶段调整，并非录制的管弦乐音轨。

## 验证

`npm test` 覆盖缺字校验、存档损坏、死亡保留字块、越界坠落、每个蹬坑与高台的可达性、体力、武器弹药、射线地形遮挡、炸弹、引水、攀绳、石碑、三阶段 BOSS 与最终通关。新增覆盖所有高台无 W 输入的单键落地、输入容错、武器自动拾取、吐弹怪、中弹倒地、绳索陡坡、点击目标接管、静止防滑，以及完整 30 秒追逐成功、急转失败和山门解锁。测试使用 Node 内置测试运行器，不依赖服务器。

### 横屏与终章引水

手机点击“开始攀登”时会尝试进入全屏并锁定横屏；方向锁定取决于浏览器支持。无法锁定时，竖屏会暂停游戏并提示手动旋转，横放后恢复。

第五关山泉从左侧流入路缘阀门处，交互开阀后向火墙引流，约 2.4 秒后灭火并移除碰撞墙，地面仅保留少量水渍。火水绘制及资源释放封装在 `src/fire-water.ts`，横屏与全屏兼容处理在 `src/display.ts`。

第五关的黑色旋涡门位于山路 128 米处，走入会自动传送到独立暗色追逐场地。完成 30 秒追逐后回到门后山路，自动获得弓箭、手枪与至少 48 发弹药并装备手枪，可继续击杀恶龙。旋涡动画封装在 `src/portal.ts`，追逐镜头同时展示玩家和身后的追兽。

追逐提示使用左侧紧凑布局，中央保留道路视野。红色子弹追踪已命中的移动目标，抵达目标处再显示命中火花与音效。恶龙一、三阶段从口部蓄力发射蓝色雷霆，二阶段喷射橙色三向龙息；第三阶段召唤带有从龙身飞出的轨迹。法术弹体与碰撞共用模拟数据，取代原先缺少视觉提示的龙息区域伤害。

雪地（冬峰与终章冬季路段）行走会留下左右交替的脚印，停下或腾空时不生成；痕迹约 50 秒后消失。第五关水闸位于左侧路缘，水从左侧山间流入，开闸后流向火墙。死亡重生与主动重开都会让所有怪物恢复初始位置与满血，已收汉字仍然保留。

旋涡门中的追逐者现为持三齿恶鬼叉的黑袍幽灵。按住任一 Shift 或屏幕“加速”可冲刺，消耗体力并拉开距离，松开后恢复；体力耗尽后恢复至 25% 才能再次冲刺。追逐期间播放心跳、低频不协和音与噪声构成的紧张配乐，幽灵靠近时节奏加快，离开追逐场地后恢复山岳音乐。

完成追逐返回山路后有 3.5 秒缓冲：恶龙保持至少 24 米距离，不会施法或召唤；缓冲结束后恢复攻击，并在玩家前方保持约 20 米间距。

对恶龙射击支持自动锁定，无需精确瞄准身体中心；点击头、翅膀或躯干都可锁定，子弹会追踪命中。地形仍会阻挡射线，恶龙自身的通关屏障不会阻挡玩家攻击。
